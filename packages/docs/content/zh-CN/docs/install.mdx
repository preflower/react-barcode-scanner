## 安装

<Tabs items={['pnpm', 'npm', 'yarn']} storageKey="package-manager">
  <Tabs.Tab>
    ```shell
    pnpm add react-barcode-scanner
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```shell
    npm install react-barcode-scanner
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```shell
    yarn add react-barcode-scanner
    ```
  </Tabs.Tab>
</Tabs>

## Polyfill

<Tabs items={['ZBar', 'ZXing']} storageKey="barcode-detector-implementation">
  <Tabs.Tab>
    ZBar 为内置依赖，无需额外安装，WASM 约为 230 kB。暂不支持 `aztec`、`data_matrix` 和 `pdf417`；如需扫描这些格式，请使用 ZXing。

    ```ts
    import 'react-barcode-scanner/polyfill'
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ZXing 需要额外安装 `barcode-detector`，其 WASM 约为 1 MiB。

    <Tabs items={['pnpm', 'npm', 'yarn']} storageKey="package-manager">
      <Tabs.Tab>
        ```shell
        pnpm add barcode-detector
        ```
      </Tabs.Tab>
      <Tabs.Tab>
        ```shell
        npm install barcode-detector
        ```
      </Tabs.Tab>
      <Tabs.Tab>
        ```shell
        yarn add barcode-detector
        ```
      </Tabs.Tab>
    </Tabs>

    ```ts
    import 'barcode-detector/polyfill'
    ```
  </Tabs.Tab>
</Tabs>

<Callout type="warning" emoji="⚠️">
  ZBar 和 ZXing polyfill 请二选一。浏览器已有原生 `BarcodeDetector` 时，polyfill 不会覆盖它。
</Callout>

## 脚手架

### Vite
建议使用最新版本的 Vite。如果 Vite 4 或更低版本无法预构建 ESM-only polyfill，可以将上游依赖排除在依赖优化之外：

```js
export default defineConfig({
  optimizeDeps: {
    exclude: ['@preflower/barcode-detector-polyfill']
  }
})
```
