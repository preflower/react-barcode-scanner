## Install

<Tabs items={['pnpm', 'npm', 'yarn']} storageKey="package-manager">
  <Tabs.Tab>
    ```shell
    pnpm add react-barcode-scanner
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```shell
    npm install react-barcode-scanner
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```shell
    yarn add react-barcode-scanner
    ```
  </Tabs.Tab>
</Tabs>

## Polyfill

<Tabs items={['ZBar', 'ZXing']} storageKey="barcode-detector-implementation">
  <Tabs.Tab>
    ZBar is included as a dependency and requires no additional installation; its WASM is approximately 230 kB. It does not support `aztec`, `data_matrix` or `pdf417`; use ZXing if you need these formats.

    ```ts
    import 'react-barcode-scanner/polyfill'
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ZXing requires installing `barcode-detector` separately; its WASM is approximately 1 MiB.

    <Tabs items={['pnpm', 'npm', 'yarn']} storageKey="package-manager">
      <Tabs.Tab>
        ```shell
        pnpm add barcode-detector
        ```
      </Tabs.Tab>
      <Tabs.Tab>
        ```shell
        npm install barcode-detector
        ```
      </Tabs.Tab>
      <Tabs.Tab>
        ```shell
        yarn add barcode-detector
        ```
      </Tabs.Tab>
    </Tabs>

    ```ts
    import 'barcode-detector/polyfill'
    ```
  </Tabs.Tab>
</Tabs>

<Callout type="warning" emoji="⚠️">
  Choose either the ZBar or ZXing polyfill, not both. A polyfill does not replace an existing native `BarcodeDetector`.
</Callout>

## Scaffold

### Vite
We recommend using the latest Vite version. If a project on Vite 4 or earlier fails to pre-bundle the ESM-only polyfill, exclude the upstream package from dependency optimization:

```js
export default defineConfig({
  optimizeDeps: {
    exclude: ['@preflower/barcode-detector-polyfill']
  }
})
```

- [Related issue](https://github.com/vitejs/vite/issues/13530)
